1. Match each of the following chi-square (χ²) terms with their corresponding definitions.
 Note: Each choice will be used exactly once.
- 1. chi-square (χ²) test statistic / A. the sum of the normalized square difference between observed and expected data
- 2.       level of significance, α / B. the fixed probability for whether or NOT the null hypothesis, H0 can be supported
- 3.             degrees of freedom / C. represents how many independent values can vary after constraints are applied
- 4.                 critical value / D. the cutoff used to compare against the observed chi-square (χ²) test statistic
- 5.                        p-value / E. a small value suggests the observed data are NOT consistent with the null hypothesis, H0


2. Match each of the following chi-square (χ²) terms with their corresponding definitions.
 Note: Each choice will be used exactly once.
- 1.            null hypothesis, H0 / A. we attempt to find evidence against this hypothesis in our chi-square (χ²) test
- 2.                        p-value / B. the probability of getting a result that is either the same or more extreme than the actual observations
- 3.     alternative hypothesis, Ha / C. this hypothesis represents a deviation or bias from the expected pattern
- 4.                 critical value / D. found in a table for a given degrees of freedom and level of significance, α
- 5. chi-square (χ²) test statistic / E. the bigger this number, the smaller the p-value
