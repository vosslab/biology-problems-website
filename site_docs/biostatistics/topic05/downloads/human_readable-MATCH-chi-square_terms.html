2. Match each of the following chi-square (χ²) terms with their corresponding definitions.
 Note: Each choice will be used exactly once.
- 1.                        p-value / A. if this value is small, then there is stronger evidence to support the alternative hypothesis, Ha
- 2. chi-square (χ²) test statistic / B. the sum of the normalized square difference between observed and expected data
- 3.                 critical value / C. the cutoff used to compare against the observed chi-square (χ²) test statistic
- 4.            null hypothesis, H0 / D. we attempt to find evidence against this hypothesis in our chi-square (χ²) test
- 5.       level of significance, α / E. the fixed probability for whether or NOT the null hypothesis, H0 can be supported
