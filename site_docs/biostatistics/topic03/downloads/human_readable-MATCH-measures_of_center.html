1. Match each of the following measures of center with their corresponding definitions.
 Note: Each choice will be used exactly once.
- 1.   Median / A. The middle value of an arranged set, splitting the data into two equal halves.
- 2. Midrange / B. The value obtained by adding the maximum and minimum values in the set, then dividing the result by two.
- 3.     Mode / C. The value that appears with the greatest frequency in the set.
- 4.     Mean / D. A central tendency measure determined by the total sum of values divided by how many values there are.


2. Match each of the following measures of center with their corresponding definitions.
 Note: Each choice will be used exactly once.
- 1. Midrange / A. The value calculated by taking the sum of the highest and lowest values and halving it.
- 2.     Mode / B. The value that appears with the greatest frequency in the set.
- 3.     Mean / C. The measure calculated by dividing the sum of all data points by the number of data points.
- 4.   Median / D. The middle number in a sorted list of values, or the average of the two central numbers if the data count is even.
